# 🔥 FLAMES Calculator

A sleek, interactive web application that calculates the relationship outcome between two names using the classic FLAMES game algorithm. Transitioned from a terminal-based C program to a modern, fully responsive web interface.

## 📖 About the Game

FLAMES is a popular childhood game used to predict the relationship status between two people. The acronym stands for:
- **F** - Friends 🤝
- **L** - Love ❤️
- **A** - Affection 😊
- **M** - Marriage 💍
- **E** - Enemies 😡
- **S** - Siblings 👫

## ✨ Features

* **Modern UI/UX:** A visually appealing, smooth interface featuring CSS gradients, glassmorphism elements, and hover effects.
* **Optimized Algorithm:** Replaced traditional nested loop counting with an efficient **Modulo Arithmetic (`%`)** approach for instant circular elimination.
* **Interactive Modals:** Clean popup windows for displaying game rules and final results without navigating away from the page.
* **Input Sanitization:** Automatically handles spaces, capitalization, and special characters to ensure accurate calculations.
* **Fully Responsive:** Works seamlessly on both desktop and mobile devices.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessible input forms.
* **CSS3:** Custom properties (variables), flexbox layouts, and keyframe transitions.
* **Vanilla JavaScript:** DOM manipulation, event handling, and core algorithmic logic.
